Edits a list field, offering the vocabulary its schema declares.

It sits on the Select rather than the shared picker control: one bare string, no query, no
chips and no read of its own, so it is a form control and wears the select trigger the other
single-value editors wear.

## Install

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/list-select.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/list-select.json
```

## Input

| chosen | emitted |
|---|---|
| an entry | that entry's value, byte for byte |
| the clear entry | `null` |

The offered set is the field's valid values, minus its hidden values when a project id is given. A
row already holding a value outside that set keeps showing it.

## Props

| prop | type | default | meaning |
|---|---|---|---|
| `value` | `string \| null` | `null` | The stored string. Two-way in Svelte. |
| `onValueChange` | `(value: string \| null) => void` | — | Called on every change. |
| `field` | `FieldSchema \| null` | `null` | Supplies the valid values, the labels and the hidden values. |
| `projectId` | `number` | — | Given, the field's hidden values are removed from the list. |
| `clearLabel` | `string` | `'Clear'` | Label of the entry that clears the field. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control height. |
| `disabled` | `boolean` | `false` | |
| `readonly` | `boolean` | `false` | |
| `invalid` | `boolean` | `false` | |
| `error` | `string \| null` | `null` | A message from the caller. |
| `placeholder` | `string` | `'Choose'` | Shown while the field is unset. |
| `open` | `boolean` | `false` | Whether the popup is showing. Two-way in Svelte. |
| `class` / `className` | `string` | — | Merged after the widget's own classes. |

A mandatory field is offered without the clear entry.

## Events

`onValueChange` fires as soon as an entry is chosen. `onErrorChange` fires with `null` on that same
change, so a message the caller set clears when the field is answered.

`onOpenChange` fires when the popup opens or closes. Svelte also binds it with `bind:open`.

## Slots

`errorMessage` receives the message and renders it.

## Keyboard

| key | does |
|---|---|
| `Space`, `Enter` | Opens the list. |
| arrows | Move the highlight. |
| `Enter` | Chooses the highlighted entry. |
| `Escape` | Closes the list, unchanged. |
| typing | Jumps to an entry by its label. |

## API behaviour

Despite the name a list field holds one bare string. A write outside `valid_values` is a 400 and
case-sensitive, down to a trailing space, so the schema's vocabulary is the whole set a picker may
offer (field_types/list).

A filter is case-insensitive where a write is not, so a value read out of a filter is never safe to
write back (field_types/list).

Hidden values reach the schema only when it is read with a project id, and REST does not enforce them
on write, so the subtraction is the client's (probe 009).
