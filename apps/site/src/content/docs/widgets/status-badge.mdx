Renders one status code as a badge carrying the site's own label, colour and icon.

## Install

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/status-badge.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/status-badge.json
```

## Props

| prop | type | default | meaning |
|---|---|---|---|
| `code` | `string` | required | The stored status code. An empty code renders nothing. |
| `status` | `StatusRecord \| null` | `null` | The resolved Status row. Supplies the label, colour and icon. |
| `field` | `FieldSchema \| null` | `null` | Fallback label source, through its display values. |
| `variant` | `'both' \| 'icon' \| 'text'` | `'both'` | Icon-only keeps the label as screen-reader text and a tooltip. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Heights 6, 8 and 10. |
| `class` / `className` | `string` | — | Merged after the widget's own classes. |

The label resolves in one order: the Status row's name, then the field's display value, then the raw
code. An unknown code renders as itself in the muted token pair.

The root carries the status code and whether it was resolved, as data attributes.

## Events

None. The badge is presentational and not interactive.

## Slots

None.

## Keyboard

Not focusable.

## API behaviour

A status_list value is a bare code with no entity behind it, so a dotted read through it returns
nothing and the label has to come from elsewhere (field_types/status_list, 009_status_lists).

Background colour arrives as comma-separated decimal RGB, never hex. The foreground is chosen by
relative luminance, so the badge stays readable in both themes (010_status_icons).

An icon's display type picks one of three renderings. An uploaded icon is a self-contained data URI.
An HTML icon is a short text label. An image-map icon names a sprite that lives in the customer
site's own stylesheet and is not in the REST API, so the badge emits the key and a coloured block,
and a rule attaches the picture (010_status_icons):

```css
[data-status-icon='icon_apr'] {
  background: url('/images/sg_icon_image_map.png') -89px -11px no-repeat;
}
```
