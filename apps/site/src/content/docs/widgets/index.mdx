Each widget page shows the Svelte and React implementations side by side. The toolbar above a demo
picks the framework, switches the demo between light and dark, and reduces motion. It also restyles
the demo with any of ten themes and overrides the corner radius. The choices carry across pages.

Widgets install from a registry into your project, one command per framework:

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/status-badge.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/status-badge.json
```

Every widget takes an `SgClient` from `@sg-widgets/core` for data. Wire your own, or the shipped REST
client.
