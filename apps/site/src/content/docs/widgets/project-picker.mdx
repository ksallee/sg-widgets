Searches projects on the server, showing each one's thumbnail and status.

## Install

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/project-picker.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/project-picker.json
```

The item holds both variants. React installs one file exporting `ProjectPicker` and
`ProjectMultiPicker`; Svelte installs `project-picker.svelte` and `project-multi-picker.svelte`.
Both configure the generic pickers, which are installed alongside.

## Props

Every prop of [EntityPicker](/widgets/entity-picker/) and
[EntityMultiPicker](/widgets/entity-multi-picker/) except `entityTypes`, plus:

| prop | type | default | meaning |
|---|---|---|---|
| `includeArchived` | `boolean` | `false` | Offer projects whose `archived` checkbox is set. |

`placeholder` defaults to `Search for a project`, or `Search for projects` on the multi picker. The
multi picker takes `summary` and `max` like every other multi picker.

The sub-label is the project's status, so an active project can be told from a bidding one.

## Events

| event | payload | when |
|---|---|---|
| `onValueChange` | `EntityRef`, `PickerRow` | The selection changed. The multi picker sends arrays. |
| `onError` | `Error` | A read failed. The list shows it inline as well. |
| `onOpenChange` | `boolean` | The popup opened or closed. Svelte also binds it with `bind:open`. |

## Slots

None.

## Keyboard

The same as [EntityPicker](/widgets/entity-picker/) and
[EntityMultiPicker](/widgets/entity-multi-picker/).

## API behaviour

Project's status field is `sg_status`, a plain list with no Status row behind it, where every other
type uses `sg_status_list` (entity_types/Project).

`sg_status` is not a liveness filter and is null on most projects; `archived`, `is_template` and
`is_demo` are the discriminators, which is why hiding archived projects filters on `archived`
(018_project_listing).

Project is site-wide and has no `project` field, so `projectId` adds nothing on this picker.

## Reference

The row, chip and checkbox anatomy follows shadcn's Base UI Combobox, read through shadcn 4.21.0.
The primitive underneath is Base UI Combobox 1.8.0 in React and Bits UI Combobox 2.19.1 in Svelte.
shadcn-svelte ships no combobox item, so each widget composes the headless primitive of its
framework and both draw the same rows, the same classes and the same states.
