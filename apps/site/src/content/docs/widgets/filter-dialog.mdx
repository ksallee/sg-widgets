A button that opens the filter editor in a dialog. Edits are staged: only Apply emits.

## Install

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/filter-dialog.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/filter-dialog.json
```

<Demo name="filter-dialog" title="FilterDialog: empty and with two filters applied" />

With no filters it is one Add filters button. With filters applied it becomes Edit filters, carries
the count of conditions that would be sent, and gains a control that clears them without opening
anything.

## Props

| prop | type | default | meaning |
|---|---|---|---|
| `entityType` | `string` | required | Type the editor reads its fields on. |
| `client` | `SgClient` | required | Passed through to the editor. |
| `schema` | `SchemaService` | one built from `client` | Passed through to the editor. |
| `value` | `FilterGroup` | `emptyFilter()` | The applied tree. Two-way in Svelte through `bind:value`. |
| `hidePaths` | `string[]` | `[]` | Passed through to the editor. |
| `label` | `string` | — | Replaces both button labels. |
| `title` | `string` | `'Filters'` | Dialog title. |
| `disabled` | `boolean` | `false` | Blocks both buttons. |
| `class` / `className` | `string` | — | Merged after the widget's own classes. |

## Events

| event | React | Svelte | payload |
|---|---|---|---|
| change | `onChange` | `onChange`, `bind:value` | The applied tree. Fires on Apply, Clear all and the clear control, never while editing. |

## Slots

`fieldChooser` and `valueEditor` are forwarded to the editor unchanged.

## Keyboard

| key | does |
|---|---|
| `Enter`, `Space` | Opens the dialog from the launcher. |
| `Tab` | Cycles inside the dialog while it is open. |
| `Escape` | Closes the dialog and drops the staged edits. |

## API behaviour

Apply sends the tree through the same serialiser the editor shows: a tree whose rows are all blank
applies as no filter, because a group with no conditions matches every row (030_complex_filters).
