Picks one entity type of a site, or several, from a searchable list of everything the site has
enabled.

## Install

```sh
pnpm dlx shadcn@latest add https://sg-widgets.dev/r/react/entity-type-picker.json
pnpm dlx shadcn-svelte@latest add https://sg-widgets.dev/r/svelte/entity-type-picker.json
```

## Props

| prop | type | default | meaning |
|---|---|---|---|
| `schema` | `SchemaService` | required | Reads the site's enabled types. Build it once per app with `createSchemaService`. |
| `value` | `string \| string[] \| null` | `null` | A type code, or an array of them in multi mode. |
| `multiple` | `boolean` | `false` | Keep the list open and take several types. |
| `onValueChange` | `(value) => void` | — | Receives the code, `null` on clear, or the new array in multi mode. |
| `allow` | `string[]` | — | Codes on offer. Empty or absent means every enabled type. |
| `deny` | `string[]` | — | Codes withheld, applied after `allow`. |
| `placeholder` | `string` | `'Select an entity type'` | Shown while nothing is chosen. |
| `searchPlaceholder` | `string` | `'Search types…'` | Shown in the search box. |
| `emptyLabel` | `string` | `'No entity type matches.'` | Shown when nothing matches. |
| `clearable` | `boolean` | `true` | Show the clear control once something is chosen. |
| `readonly` | `boolean` | `false` | Keeps full contrast and removes the chevron and the clear control. |
| `disabled` | `boolean` | `false` | |
| `invalid` | `boolean` | `false` | Applies the invalid ring and `aria-invalid`. |
| `showCode` | `boolean` | `true` | Shows the code under the display name where the two differ. |
| `summary` | `'chips' \| 'ellipsis' \| 'count'` | `'ellipsis'` | What the control shows for the selection in multi mode. |
| `max` | `number` | `0` | Chips drawn before the rest becomes `+n`. `0` lets the row fit what it can. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | |
| `open` | `boolean` | `false` | Whether the popup is showing. Two-way in Svelte. |
| `className` / `class` | `string` | — | Merged after the widget's own classes. |

Each row shows the display name, with the code beneath it in mono when the two differ, unless
`showCode` is off. In multi mode every row carries a checkbox and the list stays open across
selections.

`chips` makes the control a token field: every chip, wrapped, with the caret beside them, and
`+n` after the last chip `max` allows.
`ellipsis` makes it a one-line trigger: as many whole chips as the row fits, never a cut one,
then `+n` inline after the last, the whole list in the tooltip, and the search box at the top of
the popup.
`count` makes it the same trigger reading `3 selected`.
A single picker is always a token field, whatever `summary` says.

`allow` is applied first and `deny` second, both to the derived list rather than to the read, so a
caller narrowing the set sees the list change with no second call.

## Events

| event | payload | when |
|---|---|---|
| `onValueChange` | `string \| string[] \| null` | A type is chosen or unchosen, or the clear control is pressed. |
| `onOpenChange` | `boolean` | The popup opened or closed. Svelte also binds it with `bind:open`. |

## Slots

None.

## Keyboard

| key | does |
|---|---|
| any text | Narrows the rows, from the caret in a token field and from the popup's search box otherwise. |
| `Enter`, `Space` | On the chevron, opens the list. |
| `Down`, `Up` | Move the cursor through the rows. |
| `Enter` | Choose the highlighted type. In multi mode, toggles it and keeps the list open. |
| `Escape` | Close, keeping the value and clearing the query. |

## API behaviour

`GET /schema` returns every enabled type in about 12KB, custom slots included, and presence in that
listing is the enablement test: a slot absent from it 404s everywhere else. The display name is the
type's `name`, and the key is what a URL and a dotted path take (002_schema).

## Reference

The row, chip and checkbox anatomy follows shadcn's Base UI Combobox, read through shadcn 4.21.0.
The primitive underneath is Base UI Combobox 1.8.0 in React and Bits UI Combobox 2.19.1 in Svelte.
shadcn-svelte ships no combobox item, so each widget composes the headless primitive of its
framework and both draw the same rows, the same classes and the same states.
